# LEO Satellite Communications & Massive MIMO Research

## Overview
This repository contains research, analysis, and simulation code focused on optimizing modern satellite communication networks. The primary investigations center around downlink massive MIMO systems, joint precoding, and leveraging deep learning to enhance satellite link reliability. 

## Key Research Areas
* **Downlink Massive MIMO:** Transmit design and joint precoding strategies for multi-satellite networks.
* **Deep Learning for SatCom:** Convolutional Neural Network (CNN) based prediction models for Channel State Information (CSI).
* **LEO Satellite Handovers:** Analyzing and optimizing handover protocols for Low Earth Orbit constellations to ensure seamless connectivity.
* **Orbital Trajectory Simulations:** 3D animated modeling of LEO, Medium Earth Orbit (MEO), and Geostationary Orbit (GEO) paths using real orbital periods.

## Technologies Used
* **MATLAB:** For 3D orbital trajectory simulation and mathematical modeling.
* **Python:** For implementing deep learning algorithms and CNN-based CSI prediction.
